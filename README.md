# Internet Speed Checker for NVDA

This add-on allows you to check your internet connection speed (download, upload, and ping) directly from NVDA. It uses the professional **Speedtest.net (Ookla)** infrastructure to ensure accurate and reliable results worldwide.

## Key Features
*   **Professional Accuracy:** Powered by the Speedtest.net global network to find the nearest and fastest server for your location.
*   **Unit Customization:** Choose between Megabits per second (Mbps) or Megabytes per second (MB/s) in the settings.
*   **Accessible Results:** Test reports are displayed in a screen-reader friendly dialog.
*   **Quick Copy:** Easily copy your test results to the clipboard with a dedicated button and English voice confirmation.
*   **Native Integration:** Settings are integrated into the standard NVDA Settings dialog for a seamless experience.

## Shortcut Keys
*   `NVDA+Control+Shift+i`: Starts the internet speed check.

## Usage
1.  Press the shortcut key `NVDA+Control+Shift+i`.
2.  You will hear a periodic beep indicating the test is in progress.
3.  Once completed, a results dialog will appear showing your Download, Upload, Ping, ISP, and Location info.
4.  Use the "Copy Results" button to save the report to your clipboard or "Close" to exit.

## Configuration
To change the speed unit:
1.  Open the **NVDA Menu** (`NVDA+N`).
2.  Go to **Preferences** -> **Settings**.
3.  Select **Internet Speed Checker** from the categories list on the left.
4.  Choose your preferred unit (Megabit or Megabyte) and press **OK**.
